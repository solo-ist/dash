# Dash

A minimal, local-first task app. Part of [solo.ist](https://solo.ist) — personal
software for the AI era, sibling to [Prose](https://github.com/solo-ist/prose).

- **Local-first, private.** Your tasks live in a local database. No accounts, no
  sync, no telemetry.
- **One accent color.** The solo.ist design system: dark, paper-warm, IBM Plex
  Mono, a single muted gold.
- **Built by an agent fleet.** Dash is developed through the Solo Prime
  orchestration harness — frontier models plan and verify, local and cloud coding
  agents execute. The roadmap lives on the project board.

## Development

```bash
npm install
npm run dev
```

Electron + electron-vite + React + Tailwind/shadcn. See `AGENTS.md` for
contributor/agent conventions.
